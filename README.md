# Eastern Bluegrass Reviews v1.0

## Upload with GitHub Desktop
1. Clone `EBRLLC/eastern-bluegrass-reviews`.
2. Copy every file and folder from this package into the cloned repository.
3. Replace existing files when Windows asks.
4. In GitHub Desktop, commit to `main`.
5. Click **Push origin**.

## Required structure
- index.html
- about.html
- 404.html
- CNAME
- .nojekyll
- assets/
- articles/

## Add a new article
Copy an existing file in `articles`, rename it with lowercase hyphenated words, edit its title/body/meta tags, then add a matching card to `index.html`.
